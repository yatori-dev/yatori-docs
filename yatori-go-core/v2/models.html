数据模型 ​

V2 用一套平台无关的模型描述所有平台的数据。你只需要认识这些类型，就可以操作所有平台。

最重要的两个字段

Raw：平台原始对象，进程内使用，不能 JSON 序列化。
Extra：平台 ID 的字符串映射，可以序列化，适合存数据库或跨进程传递。

Course 课程 ​

go
type Course struct {
	ID       string
	Name     string
	Teacher  string
	Cover    string
	Progress float64
	Status   CourseStatus
	Extra    map[string]string
	Raw      any
}
字段说明
ID平台内课程 ID，作为 Tree / Study 的入口
Name课程名称
Teacher教师，可能为空
Cover封面 URL，可能为空
Progress0–100 的进度
Statusnot_started / active / finished
Extra平台需要的二级 ID，例如 cpi、key、courseId、circleId
Raw平台原始对象

常见 Extra：

平台关键字段
XUEXITONGcpi、key、classId、courseDataId、contentId
YINGHUAmode、startDate、endDate
ICVEcourseInfoId、id、courseId
CQIEstudentCourseId、coursewareId、version
ENAAEcircleId、courseId、syllabusId
QSXTsemesterId、classId、schoolId、courseId
TTCDWprojectId、orgId、itemId、segmentId、courseId
WELEARNcid、uid、classId
其他见各平台适配器

const (

Node 节点 ​

go
type Node struct {
	ID        string
	ParentID  string
	CourseID  string
	Name      string
	Kind      NodeKind
	Duration  time.Duration
	Progress  float64
	Completed bool
	Children  []Node
	Extra     map[string]string
	Raw       any
}
字段说明
ID节点 ID，Study 用它定位
ParentID父节点 ID
CourseID所属课程
Name节点名称
Kind节点类型
Duration总时长，未知时为 0
Progress0–100
Completed平台标记的完成状态
Children子节点；为空表示叶子节点
Extra平台 ID，例如 knowledgeId、cardIndex、objectId
Raw平台原始节点对象

NodeKind ​

go
const (
	NodeChapter  NodeKind = "chapter"
	NodeVideo    NodeKind = "video"
	NodeAudio    NodeKind = "audio"
	NodeDocument NodeKind = "document"
	NodeLive     NodeKind = "live"
	NodeBBS      NodeKind = "bbs"
	NodeLink     NodeKind = "link"
	NodeWork     NodeKind = "work"
	NodeExam     NodeKind = "exam"
	NodeUnknown  NodeKind = "unknown"
)

注意：并不是所有平台都能精确识别所有类型。识别不了的平台会返回 NodeUnknown，但 Study 仍可能可用。

Raw 与 Extra 怎么选 ​

场景用哪个
同一进程内马上调用 Tree / Study直接传 Course / Node，适配器会优先用 Raw
存数据库、写 JSON、跨进程保存 Extra，重建 Course{ID: id, Extra: extra}
需要平台原始字段用 Raw，但不要序列化

示例：只保存 Extra 后恢复课程

go
type SavedCourse struct {
	ID    string            `json:"id"`
	Name  string            `json:"name"`
	Extra map[string]string `json:"extra"`
}

func restore(saved SavedCourse) yatori.Course {
	return yatori.Course{
		ID:    saved.ID,
		Name:  saved.Name,
		Extra: saved.Extra,
	}
}

注意：如果某个平台只依赖 Raw 而 Extra 不完整，恢复后的课程可能无法调用 Tree。这时需要在同一次运行里重新 Courses 一次。

ID 的稳定性 ​

Course.ID / Node.ID 是适配器生成的稳定标识：

  • 学习通课程 ID 使用平台 courseId；
  • 学习通节点 ID 使用 video:<knowledgeId>:<cardIndex>:<objectId> 这类组合；
  • TTCDW 课程 ID 使用 project:segment:item:course 组合，避免不同项目下同名课程冲突。

不要自己解析 ID 的内部格式，把它当成不透明字符串使用。
